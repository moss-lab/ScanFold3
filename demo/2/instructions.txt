### Demo 2 ###

Hello! Welcome to the ScanFold3 demo/tutorial. This demo assumes ScanFold3 has been installed and the conda environment has been set up. If this isn't the case, please see the installation instructions on github and the user manual.

ScanFold3 requries a number of libraries to run. These are handled through conda, a package manager that creates an environment containing a number of libraries. 

This exercise demonstrates how to use ScanFold data as a constraint for refolding with RNAFold within the ScanFold3 program itself.

###

1. If the environment isn't active, activate it following the instructions in the previous demo.

    You should now see (ScanFold3) to the left of the command line. 

2. ScanFold3 is intended to provide constraints to other folding programs, and will generally give better results when used in that way rather than being used by itself. To refold ScanFold3 results with RNAFold automatically, run ScanFold3 using the --global_refold flag:
    python /install/location/ScanFold.py "HIV.fasta" --global_refold  

3 (optional). Compare the results from this run to the previous one in IGV. What seems to be different?
