### Demo 1 ###

Hello! Welcome to the ScanFold3 demo/tutorial. This demo assumes ScanFold3 has been installed and the conda environment has been set up. If this isn't the case, please see the installation instructions on github and the user manual.

ScanFold3 requries a number of libraries to run. These are handled through conda, a package manager that creates an environment containing a number of libraries. 

This exercise goes through a basic run of ScanFold3.

###

1. If the environment isn't active, activate it. You will know the environment is active if its name appears in parentheses next to the command line, for example:
    (ScanFold3) [ecoppen@nova18-wide-4 build]

    In order to activate the environment, use "conda activate":
    conda activate ScanFold3

    You should now see (ScanFold3) to the left of the command line. 

2. In order to run ScanFold3, you will need a fasta file. The HIV1 reference genome has been provided here. ScanFold is run using the ScanFold.py script. Optional arguments exist, but now we will just run it:
    python /install/location/ScanFold.py "HIV.fasta"

    (remember to change the path to wherever you've downloaded ScanFold!)
    
    This will create a number of files when it finishes running, and will print some debug information to the console while running. 

3 (optional). Using HIV.fasta as the genome, try opening up the files under igv_files in the Interactive Genomics Viewer program and comparing them to known annotations in HIV.gff
